# Mahagujarat Pipe Company

Static business website for Mahagujarat Pipe Company (est. 1955) — MS/GI pipes, pipe fittings, valves, flanges and industrial pipe products in Ahmedabad, Gujarat.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Frontend only (no backend, database, API, or CMS)

## Getting started

```bash
cd mahagujarat-web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run start` — serve production build
- `npm run lint` — ESLint

## Routes

- `/` — Home
- `/about` — About
- `/products` — Products catalog with filters
- `/contact` — Contact & enquiry form
